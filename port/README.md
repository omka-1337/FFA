# Far Far Away for PortMaster

Far Far Away runs the original Shrek 2 PC data on its own engine. Nothing of
the game comes with the port: you need your own copy of Shrek 2 PC, installed.

## Installing

1. Unzip `farfaraway.zip` into your ports folder, so that `Far Far Away.sh`
   and the `farfaraway` folder sit side by side.
2. Copy your installed game into `farfaraway/gamedata`, so that
   `farfaraway/gamedata/System/Default.ini` exists. The folders the engine
   reads are `System`, `Maps`, `Textures`, `StaticMeshes`, `Animations`,
   `Sounds`, `Music` and `Movies`.
3. Start Far Far Away from the Ports menu.

## Controls

The left stick moves, the right stick turns the camera. A jumps, X punches,
B grabs, Y uses, LB ducks, RB turns to the nearest, Start skips a cutscene.
In the menus A is Enter, B is back, the d-pad moves. The CFW's hotkey for
ending a port ends it.

## Logs

`farfaraway/log.txt` holds what the engine printed on its last run.
